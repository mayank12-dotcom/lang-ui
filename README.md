Lang UI is a library with professionally crafted React & Figma components for building beautiful products or starting your own design system.

<br />

## Documentation

To get started, check out the [Lang UI documentation](https://lang-ui.so/docs/getting-started/overview).

## Packages

- `lang-ui` - React design system with carefully designed components, hooks, utilities and design tokens.
  Implementation is synced with the [Lang UI Figma library](https://www.figma.com/community/file/1546133815088483407).
- `@lang-ui/headless` - headless React components and utilities for building your own design system / product with custom styles
- `@lang-ui/utilities` - framework-agnostic UI utilities built with vanilla TypeScript
